<product_requirements>
The MindConnect application is an online therapy platform for clients to connect with qualified therapists for video/audio calls, utilizing a coin-based payment system.

**Initial Core Features:**
*   **Client Side:** Browse therapists (name, photo, specialization, experience, language, rating, reviews), search/filter by mental health issue/price, book/start calls, recharge wallet (₹100 = 100 coins, 100 coins/min call deduction), view transaction history/call logs, mark favorite therapists.
*   **Therapist Side:** Create/manage profile, accept/reject calls, earn 30 coins/min from sessions, track earnings, manage schedule (Online/Offline status). (Note: Therapist profile creation later moved to Admin).
*   **Admin Dashboard:** Manage users, approve/reject therapist applications, control transactions/earnings/commissions, access analytics, control pricing/promotions.
*   **Coin & Payment:** 100 INR = 100 Coins, 100 coins/minute call rate, 30 coins/minute therapist earnings, UPI/Card recharge (mocked).
*   **Additional Features:** In-app chat (before calls), secure video calls (Agora, then Twilio), session rating/feedback, notifications, real-time wallet updates.

**Wemeto.com Inspired Feature Additions:**
*   Therapist Busy status (Online/Offline/Busy).
*   Dual pricing: Separate chat rate (100 coins/min) and call rate (150 coins/min, dynamic per therapist).
*   Subscription packages (e.g., ₹49/600 coins, ₹99/1500, ₹199/3300).
*   Enhanced Therapist Details: Hobbies, Age, Location, Phone, Gender.
*   Language Filter in client dashboard.
*   FAQ & Support pages.
*   Improved coin display on dashboards.

**Admin Specific Features:**
*   Only admins can create therapist accounts.
*   Admin can update any user's coin balance.
*   Admin can edit therapist details after creation.

**Call Management Enhancements:**
*   Therapists can see incoming calls and join sessions.
*   Therapists can end active sessions.
*   Therapists can decline incoming calls.
*   Call disconnect detection and auto-ending.
